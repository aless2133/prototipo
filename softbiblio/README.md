# Sistema de Gestión de Biblioteca Municipal “Loja Lee” — Prototipo Sprint 1

Módulo implementado:
- Gestión de Usuarios
- Registrar usuario
- Actualizar usuario
- Listado
- Historial de cambios
- Reportes básicos

## Tecnologías
- Python 3
- Tkinter
- SQLite

## Ejecución
```bash
python app.py
```

La base de datos `biblioteca_loja_lee.db` se crea automáticamente al iniciar.
